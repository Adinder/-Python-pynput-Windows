# 绝区零 (ZZZ) 弹珠/街机小游戏自动连点脚本

基于 [`pynput`](https://pypi.org/project/pynput/) 的 Windows 前台物理键鼠模拟自动化工具，专为《绝区零》（Zenless Zone Zero）小游戏场景打造。

通过 Windows `SendInput` 底层 API 发送硬件级事件，可绕过常见游戏引擎的常规软件输入屏蔽。

---

## 🎮 适用场景

* 《绝区零》街机/弹珠类小游戏重复操作挂机
* 需要前台模拟物理按键（鼠标左右键 + 空格键）的场景

> ⚠️ **注意**：脚本基于前台硬件流模拟，运行时游戏窗口必须处于**前台激活状态**，且不可最小化。

---

## ✨ 功能特性

* 🖱️ **鼠标左键点击**：模拟物理单击，间隔 **1 秒**
* 🖱️ **鼠标右键点击**：模拟物理单击，间隔 **1 秒**
* ⌨️ **空格键按下**：模拟物理按压，间隔 **2 秒**
* ⚡ **微按压延时**：每次点击保留 50ms 模拟物理按压，防止游戏高帧率下漏帧
* 🛑 **全局 F12 安全退出**：任何时候按下 `F12` 键，秒级响应终止脚本
