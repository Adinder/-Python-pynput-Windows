# 绝区零 (ZZZ) 弹珠/街机小游戏自动连点脚本

基于 [`pynput`](https://pypi.org/project/pynput/) 的 Windows 前台物理键鼠模拟自动化工具，专为《绝区零》（Zenless Zone Zero）小游戏场景打造。

通过 Windows `SendInput` 底层 API 发送键鼠输入事件，用于模拟真实的鼠标与键盘操作。

---

## 🎮 适用场景

* 《绝区零》街机 / 弹珠类小游戏重复操作
* 需要前台模拟物理按键（鼠标左右键 + 空格键）的场景

> ⚠️ **注意：** 脚本基于前台输入模拟，运行时游戏窗口必须处于**前台激活状态**，且不可最小化。

---

## ✨ 功能特性

* 🖱️ **鼠标左键点击**：模拟物理单击，间隔 **1 秒**
* 🖱️ **鼠标右键点击**：模拟物理单击，间隔 **1 秒**
* ⌨️ **空格键按下**：模拟物理按压，间隔 **2 秒**
* ⚡ **微按压延时**：每次点击保留 **50ms** 模拟物理按压，降低高帧率环境下的漏输入情况
* 🛑 **全局 F12 安全退出**：任何时候按下 `F12` 键即可终止脚本

---

## 🚀 使用方法

### 1. 安装依赖

在终端中执行：

```bash
pip install pynput
```

### 2. 以管理员身份运行终端（关键）

由于《绝区零》游戏进程（`ZenlessZoneZero.exe`）可能具有较高的运行权限，普通权限下发送的键鼠输入可能受到 Windows UIPI 权限机制影响。

建议：

1. 右键点击 **命令提示符 / PowerShell / Windows Terminal / VS Code**
2. 选择 **“以管理员身份运行”**
3. 进入脚本所在目录

例如：

```bash
cd D:\ZZZ-AutoClicker
```

### 3. 启动脚本并切换窗口

运行：

```bash
python main.py
```

脚本启动后会进行 **3 秒倒计时**。

请在倒计时期间：

1. 打开《绝区零》
2. 进入对应的小游戏界面
3. 将游戏窗口切换到前台
4. 保持游戏窗口处于激活状态

随后脚本将开始自动模拟鼠标和键盘操作。

### 4. 紧急停止

在任意界面按下：

```text
F12
```

即可立即终止脚本运行。

## 📌 注意事项

1. 脚本运行期间，《绝区零》窗口必须保持在前台。
2. 游戏窗口最小化后，前台输入模拟可能无法正常工作。
3. 如果脚本没有正常响应，可以尝试使用**管理员权限**运行终端。
4. 使用前请确认自动化操作符合游戏的用户协议及相关规则。
